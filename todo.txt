# pano-contrib. Phases from ../pano/docs/contributions-plan.md.

## Phase 1 — Skeleton
[x] Rails 8.1 app: SQLite, Solid trio, importmap, Hotwire, Rails 8 auth
[x] UUID keys, SoftDeletable, gazetteer_versions / places / buildings / devices / contributions
[x] GazetteerImport with SHA256SUMS verification; bin/rails pano:import[DIR]
[x] PanoApi client cached by ETag
[x] Map page with the pano map and the address card (Stimulus + vendored MapLibre)
[x] Anonymous devices; confirm_address, dispute_address, delivery_note, confirm_district, dispute_district, name_place
[x] rack-attack throttles per device and per IP
[x] Styleguide page; English copy in i18n
[x] Tests: models, importer, controllers, one system test at a phone viewport
[x] lefthook, CI, README

## Phase 2 — Review
[x] Accounts (email + password) claim the device and its history on sign-in or sign-up; :signups flag
[x] Votes: agree / disagree once per device and once per account, never on your own
[x] Acceptance: the plan's rules as one pure module with a table test; votes only accept
[x] Reputation counter; supersession of earlier accepted names; nightly settle job for 30-day notes
[x] Review queue at /review for moderators, moderator-only kinds first, j/k/a/r/n keys
[x] cancancan abilities; Avo at /avo and Flipper at /flipper behind AdminConstraint
[ ] Google OAuth (needs client credentials)

## Phase 3 — Changesets
[x] Changesets: draft gathers accepted contributions; export freezes changes.json (names, buildings, sub_addresses, disputed_cells)
[x] zoning --changes applies names, new buildings, sub-addresses and disputed cells; diff --json
[x] pano:applied records the churn report against the changeset; /changesets shows it
[x] Sub-addresses: LS33 9XX 17/3 in core, the API, buildings.csv and the confirm form; multi_occupancy kind

## Phase 4 — Notes and photos
[x] Delivery notes (phase 1) and homes inside shared buildings (phase 3); naming places retired
[x] Photos on notes, reports and shared-building descriptions: Active Storage with string ids, re-encoded through libvips with every metadata block stripped, scaled to 1600 px
[x] Photos shown to the author and moderators; public only once the contribution is accepted
[ ] Object storage for production (config/storage.yml amazon block)
## Phase 5 — Offline
[x] /offline: a text-only form for an address the person already knows, cached by the service worker
[x] Outbox in IndexedDB with client-minted mutation ids; replays through POST /sync/push on reconnect and every 30 s
[x] SyncApplier applies idempotently on (device, mutation id); rejected entries stay on the phone with the reason
[x] Outbox badge in the map bar
[ ] Offline map tiles (PMTiles), deferred with the Rust side
